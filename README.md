# Zombieland

## Description
3D  Game where the player tries to kill a large number of zombies, as he carefull for his life amount; try to run and kill zombies,and be carefull from failing to infinity.

## Game link 

(https://youssef2008111.itch.io/zombieland)

## How to Play
for jump click space
move right D or right arrow
move left A or left arrow
move forward W or up arrow
move backward S or Down arrow
Shoot Mouse left cursor
reload R 
Try to Kill large amount of zombie ,befor die  and watch out you bullets amounts ,be carefull from failing in infinity
